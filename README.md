# EcoScape LandAI - 风景园林AI设计助手

![LandAI](https://img.shields.io/badge/LandAI-v1.0-2D5A3D)

基于 Next.js + Tailwind CSS + Framer Motion 构建的AI辅助景观设计工具官网。

## 🌐 在线预览

- **Vercel**: https://ecoscape-landai.vercel.app
- **自定义域名**: https://ecoscapeli.com

## 🎨 设计特点

- **深色主题**: Linear风格深色版 + Notion简洁风
- **响应式**: 完美适配移动端、平板、桌面
- **动画**: Framer Motion流畅动效
- **色彩**: 森林科技绿(#2D5A3D) + 晨曦橙(#E86A33)

## 🛠 技术栈

- **框架**: Next.js 14 + React 18 + TypeScript
- **样式**: Tailwind CSS
- **动画**: Framer Motion
- **图标**: Lucide React
- **部署**: Vercel

## 📦 本地开发

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建
npm run build
```

## 🚀 部署

本项目已配置自动部署到 Vercel，推送代码到 main 分支即可自动部署。
